# 更新日志

## v0.1.12
- 修复 Windows CI 工作流中端到端测试准备脚本的 PowerShell 解析错误，改用显式替换模式与双引号以避免字符串终止符问题，并确保防火墙规则命令保持单行执行。

## v0.1.11
- 修复 Windows PowerShell 环境配置与清理步骤中中文字符串被误解析为未终止字符串的问题，统一改用单引号并移除额外转义，确保 `Set-MpPreference` 和防火墙规则调整脚本正常执行。

## v0.1.10
- 解决 Windows 环境下 gRPC 客户端共享内存测试中的 lint 警告，使用清理阶段同步等待 Serve 退出并校验返回值，避免跨协程调用 `Fatalf`。
- startMockServer 工具函数统一在清理流程里停止服务并检查退出错误，确保测试生命周期与资源释放可预测。

## v0.1.9
- 修复共享内存 JSONL 读写测试中的 protobuf 结构复制警告，统一使用指针解包返回数据。
- gRPC 客户端测试新增 Serve 失败处理并调整展开结果断言，避免 lint 检查中的锁复制问题。
- mmap 读路径显式处理 Unmap 错误，确保零拷贝读取流程的资源释放更加稳健。

## v0.1.8
- 新增基于共享内存的零拷贝通道：插件可将大体量查询结果写入 JSONL mmap 文件并通过 `SharedMemoryHandle` 返回，宿主自动展开为结构化响应。
- gRPC 执行器与工作流、HTTP 路径统一接入共享内存自动解析，避免百万行结果的 Protobuf 序列化与传输开销。
- 提供共享内存句柄读写与展开的单元测试，并允许通过 `AEGIS_SHM_THRESHOLD` 环境变量调节触发阈值。

## v0.1.7
- 引入 wazero WebAssembly 运行时，支持在 Gateway 内直接加载 wasm 插件并通过导出函数执行数据源请求。
- 扩展插件清单运行配置，新增 runtime 与 wasm 导出函数字段，可声明 alloc/execute/health_check/plugin_info 入口。
- 生命周期管理器新增 wasm 分支，直接在进程内注册执行器并复用健康检查与熔断机制，替代 gRPC 进程间通信。

## v0.1.6
- 引入基于 memberlist 的 Gossip 发现与 hashicorp/raft 共识层，提供 Gateway 集群的 Leader 选举与写入复制能力。
- 为插件安装与实例、工作流增删改操作添加 Raft 指令复制，保证多节点之间的元数据强一致。
- 在工作流执行路径增加 Leader 约束，确保只有当前 Leader 节点调度运行。

## v0.1.5
- 修复 Windows PowerShell 端 E2E 准备步骤中字符串解析失败的问题，采用显式变量与 `Set-Content` 组合写回脚本内容。
- 调整 Windows 清理日志输出的转义方式，避免再度触发字符串终止符错误。

## v0.1.4
- 修复 Windows CI PowerShell 步骤中 `sed` 调用导致的脚本解析错误，并改用 PowerShell 原生 `-replace` 更新端到端测试超时时间。
- 调整 Windows 环境清理日志的引号使用，避免字符串终止符解析错误。

## v0.1.3
- 修复 Windows 平台 CI 执行 `go tool cover` 生成覆盖率报告时的参数解析问题，强制使用 Bash 以保证跨平台兼容。

## v0.1.2
- 升级依赖 `github.com/go-viper/mapstructure/v2` 至 `v2.4.0`，消除 `GO-2025-3900` 漏洞提示并通过 `govulncheck` 扫描。

## v0.1.1
- 修复工作流边操作接口中未处理 `c.Error` 返回值导致的 lint 检查失败。

## v0.1.0
- 新增插件协议版本协商机制，启动阶段检测不兼容插件并拒绝注册。
- 引入插件运行状态监控、心跳熔断与自动恢复流程，保障主进程稳定。
- 支持插件实例的启停与热重载 API，并扩展 CLI `aegisctl` 管理命令。
- 新增插件声明 JSON Schema，规范插件仓库的 manifest 格式。
